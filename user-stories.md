# User Stories

## US-001 — Registration

### As a new user, I want to create an account so that I can make purchases.

## US-002 — Login

### As a registered user, I want to log in to my account so that I can access my account and make purchases.

## US-003 Password Recovery

### As a user who forgot password, I want to reset my password so that I can access my account again.

## US-004 Update Account Information

### As a customer, I want to update my account information so that my personal and delivery details stay up to date.

## US-005 Search Products

### As a customer, I want to search for products so that I can quickly find the product I need.

## US-006 Filter Products

### As a customer, I want to filter products so that I can find the products that match my needs.

## US-007 View Product Details

### As a customer, I want to view detailed product information so that I can decide if the product is right for me.

## US-008 Add Product to Cart

### As a customer, I want to add products to my cart so that I can buy them later.

## US-009 Remove Product from Cart

### As a customer, I want to remove products from my cart so that I can change my order before checkout.

## US-010 View Cart Total

### As a customer, I want to see the total cost of my cart so that I know how much I need to pay.

## US-011 Provide Delivery and Payment Information

### As a customer, I want to provide delivery and payment information so that I can complete my order.

## US-012 Place an Order

### As a customer, I want to place an order so that I can purchase the products I selected.

## US-013 View Order History

### As a customer, I want to view my previous orders so that I can check my past purchases.

## US-014 Check Order Status

### As a customer, I want to check my order status so that I know the current status of my order.
