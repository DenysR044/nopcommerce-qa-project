# Test Summary - nopCommerce QA Project

## 1. Overview

Testing of the nopCommerce Demo Store was performed as an independent black-box QA assessment.

The project covered the main customer flows including account management, product discovery, shopping cart, checkout, payment, order placement, and order management.

Testing was performed in September 2026 using Google Chrome 153.0.8010.48 on Windows 11 Pro 25H2.

## 2. Test Execution Summary

Two test runs were completed:

| Run ID | Run Type | Result |
|---|---|---|
| SMOKE-01 | Smoke Test | 10 Passed, 0 Failed, 0 Blocked |
| FULL-01 | Full Test Execution | 134 Passed, 1 Failed, 3 Blocked |

### Full Test Execution Results

| Status | Test Cases |
|---|---:|
| Passed | 134 |
| Failed | 1 |
| Blocked | 3 |
| Total | 138 |

**Overall Result:** Completed with Issues

The failed test case was related to the password recovery email.

Three additional password recovery test cases were blocked because the recovery email was not received.

## 3. Defect Summary

A total of 6 defects were documented during test execution and exploratory testing.

| Severity | Count |
|---|---:|
| Major | 1 |
| Minor | 5 |
| Total | 6 |

| Priority | Count |
|---|---:|
| High | 1 |
| Medium | 4 |
| Low | 1 |

The most significant issue was:

- **BUG-001 - Password recovery email is not received after a successful recovery request**

This issue prevented the complete password recovery flow from being verified.

Additional defects were identified in address validation, registration validation messages, product manufacturer data, SKU search, and product tag assignments.

All documented defects remained open at the end of testing.

## 4. Exploratory Testing Summary

Four exploratory testing sessions were completed:

- ET-001 - Checkout Address Validation
- ET-002 - Registration and Password Validation
- ET-003 - Search and Product Discovery
- ET-004 - Shopping Cart

Exploratory testing identified 5 additional defects that were not discovered during the predefined full test execution.

It also helped identify undocumented application behavior and verify additional cases related to cart quantities, product configurations, product attribute combinations, gift card data, and cart persistence.

One temporary inconsistent cart state was observed during multi-tab testing, but the issue could not be reproduced and was documented as an observation rather than a defect.

## 5. Key Findings

- The main purchase flow was successfully completed.
- Registration, login, product browsing, shopping cart, checkout, payment, order placement, order history, and order management were successfully tested.
- Password recovery could not be fully verified because the recovery email was not received.
- Several inconsistencies were identified in validation messages and catalog data.
- Product search works for regular product SKUs, but a defect was identified when searching by SKUs assigned to product attribute combinations.
- Shopping cart behavior remained stable during the additional exploratory checks.

## 6. Limitations

Testing was performed against the public nopCommerce Demo Store.

The environment may be reset periodically, and test data persistence between testing sessions is not guaranteed.

The following areas were outside the project scope:

- Performance testing
- Load testing
- Security testing
- Mobile application testing
- Third-party payment gateway internals
- Admin panel functionality
- Guest checkout flow

## 7. Conclusion

The planned smoke and full test runs were completed.

Most tested functionality worked as expected, including the main e-commerce purchase flow.

The primary functional issue identified during the full test execution affected password recovery and prevented three dependent test cases from being executed.

Exploratory testing identified additional validation, search, and catalog data issues, but no additional issue prevented the main purchase flow from being completed.

The final test execution result is **Completed with Issues**.
